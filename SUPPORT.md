# Support

AllCallAll Agent Runtime is community-maintained. Public support is provided on
a best-effort basis without guaranteed response or resolution times.

## Where to Ask

- Use the bug template for reproducible runtime defects.
- Use the feature template for orchestration, retrieval, provider, or tooling
  proposals.
- Use the documentation template for missing or inaccurate guidance.
- Include the commit SHA, Python version, service, configuration with secrets
  removed, logs, and a minimal reproduction.

Review the [documentation index](docs/README.md) and existing issues first.

## What Not to Post Publicly

Do not include provider keys, service tokens, customer context, prompts with
private data, raw traces, or exploit details in an issue. Report vulnerabilities
privately using [SECURITY.md](SECURITY.md).

Maintainers cannot provide emergency production operation, private deployment
support, model-provider support, or custom feature development through the
public issue tracker.
